# DevOps & Cloud Engineering Learning Roadmap

| Topic / Skill | Estimated Time | Focus Areas | Key Deliverables |
| :--- | :---: | :--- | :--- |
| **Linux** | 5 Days | Shell scripting, file permissions, process management, SSH | Bash automation scripts, CLI proficiency |
| **Python** | 7 Days | Syntax, data structures, file handling, libraries (`requests`, `os`) | System automation scripts, API integration |
| **GitHub** | 3 Days | Git fundamentals, branching strategies, PR workflows, merging | Repository setup, collaborative Git workflow |
| **Azure** | 7 Days | VNets, VMs, IAM (Entra ID), Blob Storage, App Services | Cloud infrastructure deployment, security configuration |
| **GitHub Actions (CI/CD)** | 4 Days | Workflows, triggers, secrets, build & release pipelines | Automated build and deployment pipelines |
| **Ansible** | 5 Days | Playbooks, inventory, roles, modules, configuration management | Automated VM configuration & provisioning |
| **K8S (Kubernetes)** | 8 Days | Pods, Deployments, Services, Ingress, ConfigMaps, Helm | AKS cluster setup, app deployment |
| **Claude AI** | 3 Days | Prompt engineering, API integration, workflow automation | AI-assisted dev workflows & script generation |
| **Total Duration** | **42 Days** | **End-to-End DevOps & Cloud Engineering** | **Production-ready CI/CD Infrastructure** |
